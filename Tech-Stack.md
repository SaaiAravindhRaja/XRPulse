# Tech Stack

## Frontend
*   **Framework:** Next.js 14 (App Router)
*   **Language:** TypeScript
*   **Styling:** Tailwind CSS
*   **Components:** shadcn/ui
*   **Icons:** Lucide React
*   **Animation:** Framer Motion

## Blockchain (XRPL)
*   **Network:** XRPL Testnet
*   **SDK:** `xrpl.js` (Client-side)
*   **Standards:** 
    *   XLS-20 (NFTs for Assets)
    *   Issued Currencies (For Fractional Shares & RLUSD)
    *   DID (XLS-40 implementation or mock via Profile)

## Backend / Data
*   **Database:** Supabase (PostgreSQL) - Stores images, descriptions, user metadata.
*   **Auth:** Supabase Auth + Wallet Signature verification.
*   **Storage:** Supabase Storage (Equipment Images).
